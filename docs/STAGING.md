# Staging — retirado do CI/CD

O environment Railway **`staging`** e a branch `staging` **não fazem mais parte do pipeline**.

Fluxo atual: [CI.md](./CI.md) — `localhost → main → Railway production`.

Se o environment `staging` ainda existir no projeto Railway, pode ser removido no dashboard quando não for mais necessário (não é mais acionado por push/CI).
